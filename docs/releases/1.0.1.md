# SuperCli 1.0.1

This maintenance release improves terminal setup, skill discovery, project context and worker coordination for both local and cloud models.

- **TUI setup:** recover arrow-key escape sequences split across terminal reads. Provider, authentication and model pickers also accept Tab and Shift+Tab. Complete key sequences stay immediate.
- **Skills:** make `apply_skill` available in minimal TUI profiles as well as the GUI. Scan skill metadata without loading every instruction body, and load one clearly matching skill with `apply_skill(query, auto=true)`. Ambiguous searches still return candidates. Only selected built-in skills are extracted.
- **Project goals:** keep project-specific goals with their project, retain explicit global goals, and refresh live goal context when switching projects or updating a goal.
- **Delegation:** enforce worker capacity when continuing a worker through `send_message`; deliver background reports at safe conversation boundaries and carry verification results back to the coordinator.
- **Agent recovery:** retain bounded action history for reflection, keep ultrawork scoped to the current run, recognize failed verification inside simple shell wrappers, and recover valid streamed tool calls after malformed blocks.
- **Efficiency:** reduce repeated memory scans and mirror writes, reuse session statistics, avoid redundant tool-argument processing and token estimation, skip unrequested file lines, and provide bounded source context with limited search results.
- **Thunderbird integration:** recover result acknowledgements without replaying mutations; make acknowledgement eviction deterministic when timestamps have coarse resolution.
- **Documentation and checks:** show GUI and English TUI screenshots in all 27 README editions and fix cross-platform test fixtures and Windows CRLF documentation checks.

## Downloads

Each portable ZIP contains both `supercli` (TUI/CLI) and `supercli-web` (GUI), public documentation and the optional built-in skill pack. Choose Windows x64, Linux x64/ARM64, or macOS Intel/Apple Silicon. On Linux/macOS, preserve executable permissions when extracting; if your extractor drops them, run `chmod +x supercli supercli-web` in the extracted folder.

GUI About and TUI `/update check` can detect this stable release. Downloads use `supercli-update.json` and `SHA256SUMS` to verify the matching bundle. Existing portable data is preserved during updates; restart after installation.
