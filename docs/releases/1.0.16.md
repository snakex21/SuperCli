# SuperCli 1.0.16

A small hotfix release for the delegation timer in the GUI, plus README
installation improvements.

## Before updating

- Back up your portable `supercli-data` directory and close other running copies
  before installing. The updater replaces the two executables, not private data,
  and a manual restart is required afterward.

## GUI

- Background delegations keep counting their working time. The immediate
  "worker started" acknowledgement used to stop the row clock at about 0.1s
  while the agent was still running. The clock now keeps ticking until the
  worker finishes, reports, fails or is stopped, and then shows the full time.
  Foreground delegations are unchanged.

## Installation and documentation

- Every README edition (27 languages) now starts "Get started" with the quick
  install commands: `install.sh` for Linux, macOS and Android (Termux), and
  `install.ps1` for Windows PowerShell. Detailed installer notes follow below.
- Removed the old `scripts/install-termux.sh`. Termux uses the root `install.sh`,
  which detects Android and selects the matching build.

## Verification

Checked with the full `go test ./...` (including the native-browser UI suite and
a regression check that the background delegation clock keeps running and stops
on completion), `go vet ./...` and README parity for all 27 languages.
