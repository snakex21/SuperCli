# SuperCli 1.0.34

Persistent memory can be switched off. Polish notes follow the English ones.

## Before updating

- Back up your portable `supercli-data` directory and close other running
  copies before installing. The updater replaces the two executables, not
  private data, and a manual restart is required afterward.
- No configuration changes are required. Memory stays on unless you switch it
  off; with memory on, SuperCli behaves exactly as in 1.0.33.

## Memory on/off

SuperCli remembers preferences, facts and earlier work between conversations.
This is still the default, and it can now be switched off:

- GUI: **Settings → Memory** (on / off / default). While memory is off a
  **memory off** chip appears next to the model button; it opens the settings.
  The Memory panel shows the same notice above the stored entries.
- TUI: `/memory off`, `/memory on`, `/memory status`, or the Memory row in
  `/settings`. While memory is off the header shows a permanent **Memory off**
  badge, also on a narrow terminal.
- One launch only: `supercli --no-memory` or `supercli-web --no-memory`
  (`--memory` forces it on).
- Environment: `SUPERCLI_MEMORY=off` / `on`.
- config.toml: `[memory]` `enabled = false`. In a project's
  `.supercli/config.toml` it applies to that project only, so you can keep
  memory on in general and off for one project (or the other way round).

When memory is off, nothing from memory is sent to the model, nothing new is
saved (facts, summaries, conversation capsules, project card, learned
patterns), the `remember` / `recall` tools are not offered, and
`search_history` only reaches the current conversation (recovering parts of it
after compaction still works). Your stored
memory is **not deleted**: switching memory back on brings it back. To delete
it deliberately, use **Clear AI memory** (Settings → Memory or Data), which
asks for confirmation.

The GUI applies the switch to the next message. In the TUI the change applies
to the next turn; a TUI session that was started with memory off needs a
restart after `/memory on`. Turning memory off changes the start of the prompt
once, so the next reply may be a little slower while the provider cache warms
up again. Conversation history itself (`/resume`, sessions) is not deleted or
changed.

All new texts are available in the 27 interface languages. Details:
`docs/configuration.md`, section "Persistent memory".

# SuperCli 1.0.34 (PL)

Pamięć można wyłączyć.

## Przed aktualizacją

- Zrób kopię przenośnego katalogu `supercli-data` i zamknij inne uruchomione
  kopie. Aktualizacja podmienia dwa pliki wykonywalne, nie dane prywatne. Po
  instalacji uruchom program ponownie ręcznie.
- Konfiguracja nie wymaga zmian. Pamięć pozostaje włączona, dopóki jej nie
  wyłączysz; z włączoną pamięcią SuperCli działa dokładnie jak w 1.0.33.

## Włączanie i wyłączanie pamięci

SuperCli zapamiętuje preferencje, fakty i wcześniejszą pracę między
rozmowami. Tak jest nadal domyślnie, a teraz można to wyłączyć:

- GUI: **Ustawienia → Pamięć** (włącz / wyłącz / domyślnie). Gdy pamięć jest
  wyłączona, obok przycisku modelu widać znacznik **Pamięć wyłączona**;
  kliknięcie otwiera ustawienia. Panel Pamięć pokazuje ten sam komunikat nad
  zapisanymi wpisami.
- TUI: `/memory off`, `/memory on`, `/memory status` albo wiersz Pamięć w
  `/settings`. Gdy pamięć jest wyłączona, nagłówek stale pokazuje znacznik
  **Pamięć wyłączona**, także w wąskim terminalu.
- Tylko na jedno uruchomienie: `supercli --no-memory` lub
  `supercli-web --no-memory` (`--memory` wymusza włączenie).
- Zmienna środowiskowa: `SUPERCLI_MEMORY=off` / `on`.
- config.toml: `[memory]` `enabled = false`. W pliku projektu
  `.supercli/config.toml` działa tylko dla tego projektu, więc można mieć
  pamięć włączoną ogólnie, a wyłączoną w jednym projekcie (albo odwrotnie).

Gdy pamięć jest wyłączona, nic z pamięci nie trafia do modelu, nic nowego nie
jest zapisywane (fakty, podsumowania, kapsuły rozmów, karta projektu, wyuczone
wzorce), narzędzia `remember` / `recall` nie są oferowane, a `search_history`
sięga tylko bieżącej rozmowy (odzyskiwanie jej fragmentów po kompresji nadal
działa). Zapisana pamięć
**nie jest usuwana**: po ponownym włączeniu wraca. Aby ją świadomie usunąć,
użyj **Wyczyść pamięć AI** (Ustawienia → Pamięć albo Dane) — z
potwierdzeniem.

GUI stosuje przełącznik od następnej wiadomości. W TUI zmiana działa od
następnej tury; sesja TUI uruchomiona z wyłączoną pamięcią wymaga ponownego
uruchomienia po `/memory on`. Wyłączenie pamięci jednorazowo zmienia początek
promptu, więc następna odpowiedź może być nieco wolniejsza, zanim cache
dostawcy znów się rozgrzeje. Sama historia rozmów (`/resume`, sesje) nie jest
usuwana ani zmieniana.

Wszystkie nowe teksty są dostępne w 27 językach interfejsu. Szczegóły:
`docs/configuration.md`, sekcja „Persistent memory”.
