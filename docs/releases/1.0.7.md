# SuperCli 1.0.7

This release fixes checkpoints and worker source context on Windows paths with short (8.3) names and updates request compatibility with OpenCode Zen.

## Windows

- Checkpoints no longer refuse to save ("inventory is incomplete or unsafe") or leave a held `.lock` file when the data folder is reached through a short 8.3 name such as `C:\Users\RUNNER~1\...` or another alias of the same path.
- Source already read by the coordinator is passed to workers correctly when the workspace path uses a short 8.3 name.

## Providers

- OpenCode Zen requests use updated session identifiers and client headers. Session IDs stay stable across turns so the provider prompt cache keeps working. Other providers are not affected.

## Other

- GUI timers no longer show "2m60s"; seconds roll over to the next minute correctly.
- PowerShell tests no longer depend on the console code page.
- CI runs the test suite on Ubuntu and cross-compiles and vets the Windows build; Windows tests are run locally.

## Verification and limitations

go test and go vet passed on Windows, along with README parity for all 27 languages; the GUI regression suite runs in CI on Ubuntu. Portable packages include GUI and TUI for Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon, with SHA256SUMS and an update manifest. Cross-compilation does not establish interactive testing on Linux or macOS.
