# SuperCli 1.0.20

Claude account sign-in with subscription usage, live quota and panel refresh,
OpenAI reasoning models on the Responses API, easier image generation and an
up-to-date Thunderbird mail tool.

## Before updating

- Back up your portable `supercli-data` directory and close other running copies
  before installing. The updater replaces the two executables, not private data,
  and a manual restart is required afterward.

## Accounts and usage

- **Claude account login**: sign in with a Claude subscription (OAuth) in the
  GUI or TUI, with token refresh and native model discovery. Credentials are
  used only for the official endpoint. See `docs/configuration.md`.
- **Subscription usage** for Claude and ChatGPT/Codex is shown in the GUI
  statistics and the TUI usage menu. Missing or old quota snapshots refresh in
  the background (at most once a minute per account, every 5 minutes while the
  app is open); a failed refresh keeps the last snapshot marked as stale.
- After a ChatGPT login the GUI offers the same "connected, start chatting"
  step as for Claude.

## OpenAI

- Official OpenAI reasoning models (`gpt-5*`, `o1`/`o3`/`o4*`, `codex*`) of an
  `openai` provider on `api.openai.com` now use the Responses API, which keeps
  the chosen reasoning level together with tools (Chat Completions silently ran
  them without reasoning). Gateways, Azure, local servers and older chat models
  are unchanged. Turn it off with `openai_reasoning_responses = false`.
- gpt-5.x reasoning requests on Chat Completions are fixed (token limit field,
  sampling, retry without effort when tools are used); the rejection is
  remembered per endpoint and model, so it costs one extra request per process.
- Responses requests use a stable `prompt_cache_key` for better cache hits;
  `response.incomplete` is treated as a truncated reply; the connection probe
  works for OpenAI model families.
- A runaway stream of whitespace tool-call arguments is stopped.

## Image and video generation

- Enabled generators are shown to the model, and their description says they
  are available, so earlier failures no longer stop the model from trying.
  Requests such as "draw a picture" or "wygeneruj obrazek" find the tool.
- Provider errors show the provider's message (for example an invalid `size`
  or `quality`), without keys.
- A `default_parameters` value missing from `allowed_parameters` is ignored with
  a note instead of failing every call.
- New: `api_key_provider` reuses a chat provider's key, local image servers,
  an optional `model` per call, and animated GIF output for gpt-image-2.6.

## Thunderbird mail

Updated for Thunderbird Bridge 0.9.32: new read-only `verify_move` and
confirmed `repair_folder`; search returns attachments only with
`include_attachments`; counts are per Message-ID (`include_duplicates` for raw
records); domain filters; Gmail label safety (`allow_other_labels`); verified
moves with a suggested re-check after a few minutes; longer timeouts for copy,
largest, folders and move; clear "safe to retry" messages for requests that
were not executed.

## GUI and TUI

- A "Jump to latest" control in long transcripts; better contrast for faint
  text in all themes.
- Goal and memory panels update live when the agent or another window changes
  them, keeping what you typed.
- Deleting a conversation waits briefly when another process holds the store.
- Faster TUI start (code styles load lazily); local Windows builds are
  stripped like release builds.
- `ctx_execute` refuses multi-line `cmd /c` scripts instead of running only
  the first line; `invoke_tool` accepts `functions.`/`tools.` prefixes and
  configured always-on catalog tools.

## Opencode Zen

- Zen inference uses the compatible transport and request metadata it
  requires.

## Verification

Checked with `go build ./...`, `go vet ./...`, `go test -p 1 ./...` (including
native-browser UI tests) and a `-H windowsgui` GUI build with a start/close
smoke test. New tests cover OpenAI Responses routing and its switch, ignored
media defaults and tool availability text, Thunderbird timeouts, re-check
notes, retry guidance and UTF-8 results.
