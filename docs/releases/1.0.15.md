# SuperCli 1.0.15

This release adds new-version notices, improves Anthropic thinking and prompt
caching, and makes tool results easier to read in the GUI.

## Before updating

- Back up your portable `supercli-data` directory and close other running copies
  before installing. The updater replaces the two executables, not private data,
  and a manual restart is required afterward.
- New-version notices are on by default. SuperCli checks GitHub Releases at most
  once a day per installed version and never downloads or installs on its own.
  Turn it off with "Update notifications" in Settings (GUI and TUI) or
  `update_notify = false` in `config.toml`.

## Update notices

- GUI: a dialog offers **Download update** or **Later**. Download opens About and
  starts the verified download; installing remains a separate button. The About
  tab keeps a dot while an update is waiting.
- TUI: one notice line suggests `/update`.
- The result is cached in `supercli-data/update-check.json` for 24 hours. Failed
  checks are not cached and never interrupt work.

## Anthropic

- Adaptive thinking for current models sends `output_config.effort` with
  summarized thinking. Older models keep `budget_tokens`, and a rejected form is
  retried once in the other form.
- Adaptive requests use a 32k output limit. This fixes empty replies after tool
  calls that hit the old 4096-token limit.
- Prompt caching uses up to three breakpoints spaced through long histories, so
  long conversations re-read less uncached context.
- The prefill budget is cleared when at least half of a call is served from cache.

## GUI tool views

- Tool input is shown as readable key/value rows instead of raw JSON. The model
  still receives the original JSON.
- Richer results for `list_dir` (tree), `search_code` (grouped by file),
  `web_lookup` (cards), `web_fetch` (header) and goal task lists.
- `load_session_image` is labelled as an image preview, with its thumbnail folded
  inside the tool row.

## Sessions and development

- Sessions that contain only system messages (for example a TUI opened and closed
  without a conversation) are no longer listed in recent sessions.
- The slowest GUI server tests run in parallel; the package suite is shorter.

## Verification

Checked with the full `go test ./...` (including 558 native-browser UI cases),
`go vet ./...` and README parity for all 27 languages. The update notice dialog
was confirmed live against the real GitHub release.
