# SuperCli 1.0.9

This release polishes the interface (code colours, readable tool names, text overflow), names sessions automatically and keeps the portable data folder smaller.

## Interface

- Code blocks are coloured in the TUI and GUI. File reads shown in tool results use the colours of the file language.
- GUI: tool names are shown in the interface language (for example "Modified file" instead of `patch_file`), with a colour per kind: reads blue, edits green, commands yellow, web purple, errors red.
- GUI: in file edits the removed text is red and the new text is green.
- Tool input and output are highlighted in the TUI and GUI.
- Long lines and wide content no longer overflow the chat.
- Sessions started in the TUI get a title locally from the first prompt when they are listed or continued in the GUI. No model call is made, and a renamed session keeps its name.

## Agent

- When the context approaches the compaction limit, the summary is prepared in the background, so compaction usually no longer blocks the turn. This only happens on backends that allow parallel requests; local single-slot backends keep the previous behaviour.
- The compaction summary input caps long older messages (head and tail are kept), so the summary request is smaller.

## Data folder

- New session databases use incremental auto-vacuum, and deleting sessions returns freed space to the disk. Existing databases are not rewritten.
- Screenshots in `.supercli/snapshots` older than 7 days are removed, but only when their exact copy is already stored with the session. The 20 newest are always kept.

## Other

- README: one-line Termux (Android) installation, in all languages.
- Fixed a rare Windows sharing violation when two sessions stored the same image at the same time.

## Verification and limitations

go test passed on Windows. The new colours and tool names were checked by unit tests and by eye in the GUI; the TUI does not yet show translated tool names or the red/green edit colours. Termux is still not tested on a physical device.
