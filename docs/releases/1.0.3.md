# SuperCli 1.0.3

This patch builds on [SuperCli 1.0.2](https://github.com/snakex21/SuperCli/releases/tag/v1.0.2), which added on-demand native desktop screenshots, local media previews and improvements to context, uploads, memory and GUI/TUI rendering.

## Visible media results

A successful `send_screenshot` or `show_media` result now shows its preview directly in the conversation, below the tool row. Previously the preview was hidden inside collapsed tool details, so a successful capture appeared to return only a path. This also applies to restored conversations and older history pages. Click an image to enlarge it.

Images retain lazy loading, portable snapshot identifiers and existing file-access checks. Diagnostic JSON remains available inside tool details. Audio and video still create no player or media request until clicked; playback does not start automatically. No image-generation service is required for taking or displaying a screenshot.

## Copy code

Fenced code blocks now have a keyboard-accessible Copy button in all 27 interface languages. It copies only the clicked block, including indentation and newlines, and has a local fallback when the browser Clipboard API is unavailable. Streaming code retains its existing text node instead of scanning or rebuilding every block on each frame.

## Verification and packages

123 GUI tests passed, including live/restored media, snapshot paths, MIME validation, exact incremental Markdown parity and clipboard success/fallback/failure. The GUI and media Go tests passed. Portable bundles include GUI and TUI for Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon, with checksum and update manifests.

Desktop control by mouse/keyboard is still a separate future feature; this release captures and previews media.
