# SuperCli 1.0.33

More fonts in the web GUI. Polish notes follow the English ones.

## Before updating

- Back up your portable `supercli-data` directory and close other running
  copies before installing. The updater replaces the two executables, not
  private data, and a manual restart is required afterward.
- No configuration changes are required. Your current font choice stays.

## More fonts

Settings → Appearance → Interface font / Code font now offers fonts that are
built into SuperCli, so they work offline and without installing anything:

- Interface: Inter, IBM Plex Sans, Atkinson Hyperlegible (designed for
  readability; Latin letters only, Cyrillic and Greek use Noto Sans), Noto
  Sans (wide character coverage).
- Code: JetBrains Mono, Fira Code, Fira Code with ligatures (`!=` as `≠`,
  `>=` as `≥`), Cascadia Code, IBM Plex Mono, Source Code Pro.

The installed Windows fonts (Segoe UI, Aptos, Arial, Tahoma, Verdana,
Trebuchet MS, Georgia; Cascadia Mono, Consolas, Courier New, Lucida Console)
are still there. "Custom…" takes the name of any font installed on your
computer; if it is not installed, the system font is used. A preview under
the two lists shows sample text (Polish and Cyrillic) and code in the chosen
fonts.

All built-in fonts are under the SIL Open Font License 1.1; the licences and
sources are in `LICENSES/fonts/` and `THIRD_PARTY_NOTICES.md`. The GUI
program grows by about 1.8 MB.

# SuperCli 1.0.33 (PL)

Więcej czcionek w GUI.

## Przed aktualizacją

- Zrób kopię przenośnego katalogu `supercli-data` i zamknij inne uruchomione
  kopie. Aktualizacja podmienia dwa pliki wykonywalne, nie dane prywatne. Po
  instalacji uruchom program ponownie ręcznie.
- Konfiguracja nie wymaga zmian. Obecny wybór czcionek zostaje.

## Więcej czcionek

Ustawienia → Wygląd → Czcionka interfejsu / Czcionka kodu mają teraz czcionki
wbudowane w SuperCli, więc działają bez internetu i bez instalowania:

- Interfejs: Inter, IBM Plex Sans, Atkinson Hyperlegible (zaprojektowana pod
  czytelność; tylko łacinka, cyrylica i greka używają Noto Sans), Noto Sans
  (szeroki zakres znaków).
- Kod: JetBrains Mono, Fira Code, Fira Code z ligaturami (`!=` jako `≠`,
  `>=` jako `≥`), Cascadia Code, IBM Plex Mono, Source Code Pro.

Czcionki zainstalowane w Windows (Segoe UI, Aptos, Arial, Tahoma, Verdana,
Trebuchet MS, Georgia; Cascadia Mono, Consolas, Courier New, Lucida Console)
nadal są dostępne. „Własna…” przyjmuje nazwę dowolnej czcionki zainstalowanej
na komputerze; jeśli jej nie ma, używana jest czcionka systemowa. Podgląd pod
listami pokazuje przykładowy tekst (po polsku i cyrylicą) oraz kod w wybranych
czcionkach.

Wszystkie wbudowane czcionki są na licencji SIL Open Font License 1.1;
licencje i źródła są w `LICENSES/fonts/` i `THIRD_PARTY_NOTICES.md`. Program
GUI rośnie o ok. 1,8 MB.
