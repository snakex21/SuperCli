# SuperCli 1.0.6

This release adds cheap-model review with takeover by a stronger model, a hard evaluation suite, and fixes for terminal input, onboarding paste and overloaded API providers. The selected thinking controls are preserved.

## Review and takeover

- A cheaper or local model can do the work while a stronger model reviews it (`review_model`, `review_max_rounds`, `review_takeover`, `review_handoff_after`). The reviewer approves, asks for a correction, or takes over the task. A run that exceeds the handoff time is passed to the reviewer.
- Batch traces record verify-command output for each review round, so a failing check is visible next to the verdict.
- On the hard evaluation suite (9 tasks with hidden tests), a local Qwen 27B worker reviewed by a Codex model completed 9/9 and used about half of the reviewer's input tokens compared with the reviewer working alone.

## Terminal and processes

- On Linux and macOS, child processes run in their own session, so prompts from git, ssh or sudo cannot stop the agent or take terminal input.
- Pasting an API key or URL during TUI onboarding no longer loses or splits the pasted text.

## Providers

- Anthropic-compatible gateways get more retries on HTTP 503 within the same wait budget.
- Provider verification explains overloaded upstreams (500/502/503/504/529) and models a provider does not serve through its API, instead of suggesting a wrong key or URL.

## Other

- Persistent usage history and charts, source evidence tracking for workers, search outline, nested repository checkpoints and project instructions.
- Lower inactive memory use of the Windows GUI through the WebView2 API.
- Locale updates.

## Verification and limitations

go vet and the GUI regression suite passed on Windows, along with README parity for all 27 languages. Portable packages include GUI and TUI for Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon, with SHA256SUMS and an update manifest. Cross-compilation does not establish interactive testing on Linux or macOS.
