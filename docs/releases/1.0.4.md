# SuperCli 1.0.4

This release adds account-aware Codex discovery and usage dashboards, and includes the performance, media and provider fixes made since 1.0.3.

## Codex accounts and models

- Saved ChatGPT logins now appear as a Codex provider even when no provider entry was created before. Windows UTF-8 BOM imports and a single named account are supported.
- Available models, context windows, image support and reasoning levels come from the signed-in accounts' native model catalog. New advertised models require no hardcoded catalog update. A portable metadata cache bounds automatic discovery; an explicit provider scan refreshes it.
- GUI Accounts/Usage and TUI Usage → Accounts show limits per account and an account summary, including actual window duration, used/remaining percentage, reset, plan and credits when the server supplies them. Missing values remain unknown. Pro accounts with no five-hour window are displayed without one. Percentage limits of different accounts are not added together.
- Usage refresh is manual and does not run a model completion. Remove account is available in GUI; Del removes the selected local login in the TUI accounts menu. Other accounts remain available.
- Round robin now rotates across healthy eligible accounts. Fresh observed exhausted quotas are skipped, expired/unknown observations remain eligible, and errors after any generated output never trigger another account's duplicate response. Account changes take effect for subsequent work without a model handoff or history reset.

Existing rejected/expired credentials still require login; discovery cannot renew a revoked token or bypass an upstream HTTP 403.

## Agent, media and interface fixes

- AnyRouter models choose their appropriate Messages, Responses or Chat API route; the existing OpenCode Zen route is preserved.
- GUI reasoning appears before the answer even when its provider summary arrives late. Generation speed uses measured generation timing, rather than prompt-processing time or an assumed clock.
- Image-reading previews stay inside tool details; explicitly shared media remains visible in chat. Tool and thinking disclosure preferences persist.
- Covered application-window screenshots, bounded image encodings, scoped desktop/headless work and delegated recovery received fixes. Desktop capture and capture of a named application remain separate operations.
- GUI/TUI history rendering, SSE handling, request preparation, image sampling and retained payloads perform less repeated work and retain fewer unnecessary copies. Rewind uses direct message lookup, and retired title callbacks cannot rename another conversation.
- The TUI no longer stores a second raw full-history mirror. In a controlled 2,400-message resume fixture, this reduced allocated memory by about 3.3 MB while preserving identical public copy/search output. This is not a claim about total process or WebView memory.

## Verification and portable packages

The Go package tests, go vet, 202 GUI regression tests and README parity checks for all 27 languages passed. Model discovery, quota windows, account removal and rotation have synthetic regression coverage. Live read-only attempts on the existing saved logins were rejected by upstream credentials/HTTP 403; no successful live model entitlement or generation claim is made.

Portable packages include GUI and TUI for Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon. SHA256SUMS and the update manifest accompany the five ZIP files. Linux/macOS binaries were cross-compiled; interactive testing on those operating systems is separate from build verification.
