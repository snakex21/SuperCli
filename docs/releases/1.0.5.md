# SuperCli 1.0.5

This release improves command cancellation, agent efficiency and durable usage statistics. It preserves the user's selected thinking controls and applies the agent changes through shared contracts rather than rules for particular websites or model names.

## Commands, downloads and project data

- Stopping GUI/TUI work cancels its owned commands and clears completed command activity, including command failures and interrupted streams. Command continuations and background process lifetimes have regression coverage.
- Downloads use declared resource links and checked output receipts. Repeated successful operations can reuse verified results when their authorization and destination remain valid. Requests for several distinct files still complete each requested output.
- Project removal has explicit checkpoint cleanup behavior, and retained diagnostics/checkpoints use bounded portable storage. Application state remains beside the executable; release packages contain no user configuration, credentials or conversation databases.
- Checkpoint Git commands handle generated reference paths exceeding Windows' legacy path limit through a command-local option, without changing global Git configuration or Windows settings. Capture, Undo/Redo and retention inventory have a native regression test for long references.

## Agent efficiency and context

- Shared tool contracts expose requested operations more directly, support independent batching and reduce repeated discovery, reads and already-completed effects. New instructions, changed state, failures and independent goals remain eligible for fresh work.
- Native repository preflight reuses executable resolution and performs less repeated Git/status processing. Local measurements show lower preparation allocations; they do not establish a universal reduction in whole-turn latency.
- Compaction preparation avoids redundant summary envelopes and skips a manual compaction consisting only of an already recognized saved summary. Conversation constraints, file facts and the selected thinking controls are preserved.
- Anthropic streams complete on their terminal protocol event instead of waiting for an already-completed HTTP body to close. Final usage and native reasoning signatures are retained.
- Context indicators use provider/runtime metadata and the active model's loaded limit when available. Model changes refresh the displayed limit; unknown limits remain unknown. Local thinking controls remain available for models advertising a toggle.

## Persistent statistics and costs

- Saved conversations restore their token totals, last-turn usage and measured average generation speed. Unmeasured calls are marked as unknown instead of inventing a rate.
- Token details show per-model and per-purpose usage, reported reasoning as part of output, cache as part of input, and measured generation timing. Charts and details stay in popups so the main statistics panel remains compact.
- Cost details group usage by model. Settings provide a display currency, and usage records retain their price and historical exchange-rate snapshots. Older incomplete records are explicitly estimated or marked unavailable; changing today's prices/rates does not silently reprice recorded history.
- Currency selection, historical-rate retrieval, popup layout and resumed-session statistics received fixes. Local or included-plan calls remain distinguishable from metered API estimates.

## Verification and limitations

The full Go suite and go vet passed on Windows, along with 309 GUI regression tests, 11 README checker tests and documentation parity for all 27 languages. Portable packages include GUI and TUI for Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon, with SHA256SUMS and an update manifest. Cross-compilation does not establish interactive testing on Linux or macOS.

The historical approximately 116-second compaction preparation delay remains under diagnosis. A single identical-input trace observed checkpoint copying and pagefile reads but did not reproduce that long delay; concurrent RAM pressure may affect results. This release does not claim to fix that delay or universally accelerate summary generation, and does not lower thinking, shorten agreements or alter the external inference runtime.
