# SuperCli 1.0.11

This release fixes first-run provider setup and command menus in Termux, makes
async delegation continue automatically, and repairs image delivery and session
replay.

## Termux and providers

- First-run setup accepts working OpenCode Zen free models using the same
  tool-capable transport as normal agent requests.
- Typing `/` shows and filters the command menu while the AI is working. Local
  commands preserve cancellation, and unsafe changes stay blocked during a run.
- File completion preserves the rest of the draft, including multiple lines.
- `/usage` shows token and cost information for non-Codex providers; Codex keeps
  its subscription-limit view.

## Tools and delegation

- Responses tool calls preserve names, arguments and identities across partial
  and terminal events, without executing repeated completion events twice.
- Exact registered tool names wrapped in `functions.` or `tools.` are accepted.
  Malformed-call feedback no longer encourages searching for `invalid_tool_call`.
- The main agent waits for its own async workers and consumes their reports
  automatically, without requiring a user to type "continue".
- Reports already used by the current request do not trigger another model
  call. Async acknowledgments explain waiting and distinguish worker IDs from
  output handles, reducing redundant delegation and polling attempts.
- The GUI pauses its model-inactivity timer during actual host waiting and
  terminal checkpoint writes, then restores it for the next model request.
  Cancellation and worker limits remain active.

## Images and session history

- Anthropic requests send images when dynamic capability metadata is unknown;
  explicit text-only settings and actual endpoint rejections remain respected.
- Parallel image tools keep every tool result together before auxiliary image
  messages, including in persisted history.
- Reopening a session keeps tool-returned images under their tool result instead
  of creating another user message. Strictly identifiable legacy messages are
  handled too, without rewriting stored conversations or genuine attachments.

## Reliability and compaction

- Checkpoint Git failures retain cancellation/deadline causes alongside native
  diagnostics. A cancelled ref lookup is not treated as a missing ref.
- When optional performance-budget compaction cannot shrink an older prefix,
  the exact history is retained and the same prefix is not summarized every
  step. Hard context-limit errors continue to fail explicitly.
- User-selected thinking levels are unchanged.

## Verification

The full Go suite passed on Windows, followed by fresh agent/GUI/TUI regressions,
full `go vet`, all 317 UI tests and documentation checks for all 27 languages.
Live OpenCode Zen tests covered setup and a coordinator with two real async
workers; three consecutive delegation trials finished with three coordinator
tool calls and no errors. Anthropic image transport was checked with actual PNG
bytes against controlled HTTP fixtures, without a paid production API call.
Android ARM64 is cross-compiled; physical-device Termux testing remains pending.

Portable bundles include both executables and public application assets. Keep
your existing `supercli-data/` folder when updating.
