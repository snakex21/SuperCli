# SuperCli 1.0.17

Delegation and GUI polish, plus faster QEMU control for agents.

## Before updating

- Back up your portable `supercli-data` directory and close other running copies
  before installing. The updater replaces the two executables, not private data,
  and a manual restart is required afterward.

## GUI

- Delegated workers now show image thumbnails. When a worker takes a screenshot
  or reads an image, its activity row opens a small preview, like tool rows in
  the main conversation. This applies to new delegations; older saved sessions
  did not record the image files.
- The context bar on the statistics tab updates live while the agent works
  (throttled to once per second and only while that tab is visible), instead of
  only after switching tabs.
- `send_screenshot` is shown as "Screenshot" in all 27 languages instead of the
  raw tool name.

## Headless QEMU control

- New QMP action `type`: sends a whole text as keystrokes in one call (`\n` is
  Enter), with a short hold per key and a configurable pause (`delay_ms`). The
  text is checked before the first key is sent, so an unsupported character
  never leaves a half-typed command. `layout` selects the guest keyboard: `us`
  (default, ASCII) or `pl` (Polish programmer, adds ąćęłńóśźż via AltGr).
  It is allowed by the existing `keys` grant.
- `screenshot_after=true` on `keys`, `click` or `type` waits `settle_ms`
  (default 300) and returns the resulting screen in the same call, saving a
  separate model request. It also requires the `screenshot` grant.
- The tool description now recommends reading the guest's serial output
  (`-serial file:` or `-serial stdio`) instead of inferring text from
  screenshots.

## Verification

Checked with the full `go test ./...` (including the native-browser UI suite,
a browser test for live context-bar refresh and worker thumbnails, and QMP
fixture tests for `type`, the Polish layout and `screenshot_after`),
`go vet ./...` and README parity for all 27 languages. QEMU changes were tested
against a protocol fixture, not a live virtual machine.
