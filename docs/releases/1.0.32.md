# SuperCli 1.0.32

Tool rows in the web GUI show the kind of tool in colour again. Polish notes
follow the English ones.

## Before updating

- Back up your portable `supercli-data` directory and close other running
  copies before installing. The updater replaces the two executables, not
  private data, and a manual restart is required afterward.
- No configuration changes are required.

## Coloured tool rows

Since 1.0.26 every tool row in the conversation had a grey symbol and a
white title, so reading, editing, commands and web access looked the same.
The symbol and the title are coloured by the kind of tool again:

- ◇ blue: reading and searching (Odczyt pliku, Szukanie w kodzie, …)
- ◆ green: changing files
- $ amber: commands
- ◎ violet: web

A row that failed, was denied or waits for your approval still takes the
status colour (red, muted red, amber), so a failed change is never green.
Worker activity rows follow the same rule.

## Fonts

If tool titles look like a serif font (Georgia) and code like Courier New,
that is the font choice in Settings → Appearance ("Interface font", "Code
font"); choose "System" and "System monospace" to get Segoe UI and
Consolas/Cascadia back.

# SuperCli 1.0.32 (PL)

Wiersze narzędzi w GUI znów pokazują rodzaj narzędzia kolorem.

## Przed aktualizacją

- Zrób kopię przenośnego katalogu `supercli-data` i zamknij inne uruchomione
  kopie. Aktualizacja podmienia dwa pliki wykonywalne, nie dane prywatne. Po
  instalacji uruchom program ponownie ręcznie.
- Konfiguracja nie wymaga zmian.

## Kolorowe wiersze narzędzi

Od 1.0.26 każdy wiersz narzędzia w rozmowie miał szary symbol i biały tytuł,
więc odczyt, zmiany, komendy i sieć wyglądały tak samo. Symbol i tytuł znów
mają kolor rodzaju narzędzia:

- ◇ niebieski: odczyt i wyszukiwanie (Odczyt pliku, Szukanie w kodzie, …)
- ◆ zielony: zmiany w plikach
- $ bursztynowy: komendy
- ◎ fioletowy: sieć

Wiersz, który się nie powiódł, został odrzucony albo czeka na zatwierdzenie,
nadal ma kolor stanu (czerwony, przygaszony czerwony, bursztynowy), więc
nieudana zmiana nigdy nie jest zielona. Wiersze aktywności podagentów działają
tak samo.

## Czcionki

Jeśli tytuły narzędzi wyglądają jak czcionka szeryfowa (Georgia), a kod jak
Courier New, to jest wybór czcionek w Ustawieniach → Wygląd („Czcionka
interfejsu”, „Czcionka kodu”); wybierz „Systemowa” i „Systemowa o stałej
szerokości”, żeby wrócić do Segoe UI i Consolas/Cascadia.
