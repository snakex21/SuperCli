# SuperCli 1.0.8

This release adds agent modes (post-work review model, advisor and Darwin switches), handles retired OpenCode Zen models automatically, adds an experimental Termux (Android) bundle and makes several smaller speed and UI improvements.

## Agent

- New modes in settings (TUI and GUI): the advisor can be turned off, an optional review model checks finished work, and Darwin is now off by default because N candidates cost N times more. `/darwin` still works on demand.
- A dropped model stream is retried once instead of failing the turn.
- `ctx_execute` notices when a command waits for interactive input (for example a confirmation prompt) and reports it instead of hanging until the timeout. Compiler and test output lines such as `x_test.go:12: bad value:` are no longer mistaken for prompts.
- Shorter tool descriptions make every request slightly smaller.

## Providers

- OpenCode Zen: when a model is retired (HTTP 410 `ModelDeprecated`), the request is retried once on the successor named by Zen and the mapping is remembered for later turns. Other providers are not affected.

## Termux (Android) — experimental

- New `android_arm64` bundle and a one-line installer: `curl -fsSL https://raw.githubusercontent.com/snakex21/SuperCli/main/scripts/install-termux.sh | sh`. Running it again updates the binaries and keeps `supercli-data`. (Since 1.0.15 this script is removed; use the root `install.sh` instead.)
- DNS and CA certificates are found inside Termux, and Codex login uses the headless flow there.
- Not yet tested on a physical device.

## Interface

- Thinking blocks collapse automatically once the answer is complete (TUI and GUI).

## Other

- Releases are published directly when the version tag is pushed.
- `--trace-jsonl` reports a per-request prompt breakdown; `supercli-eval` can run tasks in parallel with `-jobs`.
- Windows test fixtures no longer flash buttons on the taskbar.

## Verification and limitations

go test and go vet passed on Windows; a local evaluation with qwen3.8-27b (LM Studio) passed 10/10 tasks. The GUI regression suite and README parity check run in CI on Ubuntu. Portable packages include GUI and TUI for Windows x64, Linux x64/ARM64, Android ARM64 (Termux) and macOS Intel/Apple Silicon, with SHA256SUMS and an update manifest. Cross-compilation does not establish interactive testing on Linux, macOS or Android.
