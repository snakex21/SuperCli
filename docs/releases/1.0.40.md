# SuperCli 1.0.40

Workers that stopped on a usage limit resume when you ask in plain words,
and resumed workers run on the model and reasoning you chose since. Polish
notes follow the English ones.

## Before updating

- Back up your portable `supercli-data` directory and close other running
  copies before installing. The updater replaces the two executables, not
  private data, and a manual restart is required afterward.
- No configuration changes are required.

## Resuming workers

- A plain request resumes them: "wznów je", "możesz wznowić te modele",
  "kontynuuj workery" or "resume them" (also in the other UI languages)
  resumes every worker that stopped on a rate or usage limit, a connection
  or server error, or a restart. You no longer have to type worker ids.
- Numbers narrow it ("wznów 363"), "but not 376" leaves one out, and "nie
  wznawiaj" resumes nothing. Workers you stopped yourself and tasks that
  genuinely failed run again only when you name them; the coordinator asks
  about them.
- When several workers are waiting, the worker panel shows one
  "Resume all (N)" button.
- Automatic turns still never resume a worker on their own.

## Worker model and reasoning

- Resuming, retrying or continuing a worker uses the current worker model
  and reasoning settings, not the ones it was started with. A running worker
  is not switched mid-run; the change applies at its next run.
- The worker card shows the model of the current run, and a resumed run on
  another model adds one "Model: old → new" line to its activity.

## Tests

New tests cover the resume requests (the reported Polish sentence resumes
all five limited workers, negation resumes none, a number resumes only that
worker, a user-stopped worker is left out, English and button prompts), the
current worker model and reasoning on resume, a running worker that keeps
its model, and the "Resume all" button and model line in the UI.

# SuperCli 1.0.40 (PL)

Agenci zatrzymani przez limit użycia wznawiają się na zwykłą prośbę, a
wznowieni agenci pracują na modelu i rozumowaniu wybranym przez Ciebie
później.

## Przed aktualizacją

- Zrób kopię przenośnego katalogu `supercli-data` i zamknij inne uruchomione
  kopie. Aktualizacja podmienia dwa pliki wykonywalne, nie dane prywatne. Po
  instalacji uruchom program ponownie ręcznie.
- Konfiguracja nie wymaga zmian.

## Wznawianie agentów

- Wystarczy zwykła prośba: „wznów je”, „możesz wznowić te modele”,
  „kontynuuj workery” czy „resume them” (także w innych językach
  interfejsu) wznawia wszystkich agentów zatrzymanych przez limit, błąd
  połączenia lub serwera albo restart. Nie trzeba już przepisywać numerów.
- Numery zawężają prośbę („wznów 363”), „ale nie 376” pomija jednego, a
  „nie wznawiaj” nie wznawia nikogo. Agenci zatrzymani przez Ciebie i
  zadania, które naprawdę się nie udały, ruszają tylko wtedy, gdy je
  wskażesz; koordynator o nie dopyta.
- Gdy czeka kilku agentów, panel agentów pokazuje jeden przycisk
  „Wznów wszystkie (N)”.
- Tury automatyczne nadal same niczego nie wznawiają.

## Model i rozumowanie agentów

- Wznowienie, ponowienie lub kontynuacja agenta używa bieżących ustawień
  modelu i rozumowania agentów pomocniczych, a nie tych z chwili startu.
  Pracujący agent nie jest przełączany w trakcie; zmiana działa od jego
  następnego uruchomienia.
- Karta agenta pokazuje model bieżącego uruchomienia, a wznowienie na innym
  modelu dodaje do aktywności jedną linię „Model: stary → nowy”.

## Testy

Nowe testy obejmują prośby o wznowienie (zgłoszone zdanie wznawia wszystkich
pięciu agentów, przeczenie nikogo, numer tylko wskazanego, agent zatrzymany
przez użytkownika jest pomijany, prośby po angielsku i z przycisku), bieżący
model i rozumowanie po wznowieniu, pracującego agenta, który zachowuje model,
oraz przycisk „Wznów wszystkie” i linię modelu w interfejsie.
