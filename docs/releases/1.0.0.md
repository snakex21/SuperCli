# SuperCli 1.0.0

GUI and TUI now share 27 interface languages, including native language names in the picker. The main English README and its complete translations have matching sections, commands, links and examples.

Updates are explicit: check for a stable release, download a matching bundle verified against its SHA256 manifest, then install both executables and restart. Downloads, receipts and executable backups remain beside the application in `supercli-updates/`; existing portable data is preserved. Installation is refused while the current application has an active foreground run or worker.

The GUI loads the selected catalog on demand. TUI catalogs are parsed once per selected language, without parsing all 27 at startup. GUI startup reuses its settings response for draft recovery and avoids a redundant reasoning lookup when no model is selected. Settings, recovered drafts and attachment preferences are stored in the portable backend; old browser preferences are read once for migration without new browser storage writes.

Agent fixes include project-relative executable resolution, accurate command status when output pipes stay open, missing edit argument checks, repair of read-many list arguments, and rejecting ambiguous file edit anchors.

Portable Windows amd64, Linux amd64/arm64 and macOS Intel/Apple Silicon bundles contain the CLI, GUI, public documentation and optional built-in skill pack. The release workflow prepares a draft; publication remains a separate review step.

[GUI and TUI screenshots](../screenshots/1.0.0/README.md). Catalog and README parity is checked automatically; translations have not received a native-speaker review in every language.
