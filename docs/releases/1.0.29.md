# SuperCli 1.0.29

Fixes for custom OpenAI-compatible providers such as Logfare and for the side panel tabs in the web GUI. Polish notes
follow the English ones.

## Before updating

- Back up your portable `supercli-data` directory and close other running
  copies before installing. The updater replaces the two executables, not
  private data, and a manual restart is required afterward.
- No configuration changes are required.

## Models that cannot call tools

Some models cannot call tools, but they do not reject a request that includes
them either. They answer with HTTP 200 and simply never call the tools. A live
test of Logfare found this with a model listed as `tools: false`: given "read
notes.txt" with tools attached, it replied with 2048 tokens of unrelated text.
The 1.0.28 fallback only handles a request that is rejected with an error, so
it never applied here.

Now, before the first request with tools to a remote custom endpoint,
SuperCli reads that endpoint's model list once per run. A model the list marks
as unable to call tools is sent no tools, and you see the notice "does not
support tool calling … pick a function-calling model for agent work".

Model lists without that information, and local servers, behave as before, as
do the OpenAI and Anthropic APIs. For agent work on Logfare, use
`logfare/auto` or a model that supports tools.

## Logfare limits

Logfare reports your account's current per-minute limit in the
`x-ratelimit-limit-requests`, `x-ratelimit-remaining-requests` and
`x-ratelimit-reset-requests` response headers. The live test showed 80 per
minute; Logfare's documentation says 40 per minute for regular accounts. Set
`requests_per_minute` slightly below the value in these headers.
`docs/configuration.md` describes this.

## Side panel tabs no longer overlap

In the web GUI's right side panel, long tab names (for example
"STATYSTYKI ROZMOWY" in Polish or "STATISTIKEN GESPRÄCHE" in German) ran into
each other when the panel was narrow. Each tab is now at least as wide as its
name, and a tab row that does not fit scrolls sideways, with a faded edge
showing there is more. The active tab scrolls into view and keeps its
underline. Each tab also shows its full name as a tooltip. A browser test
checks every one of the 27 languages at the narrowest panel width and at
400 px, with the app font and with a wide fallback font.

# SuperCli 1.0.29 (PL)

Poprawki dla niestandardowych dostawców zgodnych z OpenAI, np. Logfare, oraz dla zakładek panelu bocznego w GUI.

## Przed aktualizacją

- Zrób kopię przenośnego katalogu `supercli-data` i zamknij inne uruchomione
  kopie. Aktualizacja podmienia dwa pliki wykonywalne, nie dane prywatne. Po
  instalacji uruchom program ponownie ręcznie.
- Konfiguracja nie wymaga zmian.

## Modele, które nie obsługują narzędzi

Niektóre modele nie obsługują narzędzi, ale nie odrzucają też zapytania, które
je zawiera. Odpowiadają HTTP 200 i po prostu nigdy ich nie wywołują. Test na
żywo z Logfare wykazał to dla modelu oznaczonego `tools: false`: na polecenie
„przeczytaj notes.txt” z dołączonymi narzędziami odpowiedział 2048 tokenami
niezwiązanego tekstu. Mechanizm awaryjny z 1.0.28 obsługuje tylko zapytanie
odrzucone z błędem, więc tutaj się nie włączał.

Teraz przed pierwszym zapytaniem z narzędziami do zdalnego niestandardowego
dostawcy SuperCli raz na uruchomienie czyta jego listę modeli. Model, który
według tej listy nie obsługuje narzędzi, dostaje zapytanie bez narzędzi, a
użytkownik widzi komunikat „does not support tool calling … pick a
function-calling model for agent work”.

Listy modeli bez tej informacji i serwery lokalne działają jak dotąd, podobnie
jak API OpenAI i Anthropic. Do pracy agenta w Logfare używaj `logfare/auto`
albo modelu z obsługą narzędzi.

## Limity Logfare

Logfare podaje aktualny minutowy limit konta w nagłówkach odpowiedzi
`x-ratelimit-limit-requests`, `x-ratelimit-remaining-requests` i
`x-ratelimit-reset-requests`. Test na żywo pokazał 80 zapytań na minutę;
dokumentacja Logfare podaje 40 na minutę dla zwykłych kont. Ustaw
`requests_per_minute` nieco poniżej wartości z tych nagłówków. Opis jest w
`docs/configuration.md`.

## Zakładki panelu bocznego już na siebie nie nachodzą

W prawym panelu bocznym GUI długie nazwy zakładek (np. „STATYSTYKI ROZMOWY”
po polsku albo „STATISTIKEN GESPRÄCHE” po niemiecku) nachodziły na siebie,
gdy panel był wąski. Każda zakładka jest teraz co najmniej tak szeroka jak jej
nazwa, a rząd zakładek, który się nie mieści, przewija się w bok z
wygaszoną krawędzią, która pokazuje, że jest więcej. Aktywna zakładka
przewija się do widoku i zachowuje podkreślenie. Pełna nazwa jest też w
podpowiedzi. Test w przeglądarce sprawdza wszystkie 27 języków przy
najwęższym panelu i przy 400 px, z czcionką aplikacji i z szeroką czcionką
zastępczą.
