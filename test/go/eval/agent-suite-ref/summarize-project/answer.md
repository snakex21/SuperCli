tinyqueue is a small background job queue. Entry point: python -m tinyqueue.cli with commands enqueue, run and stats. Failed jobs are retried up to max_attempts = 5 with exponential backoff (2 * 2**(attempt-1) seconds, capped at 60 s), then marked dead. Jobs are persisted append-only to a JSON Lines file (jobs.jsonl) by JsonlStore. Config comes from tinyqueue.toml, and the TINYQUEUE_DB environment variable overrides the store path.
